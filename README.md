## 遊戲簡介

你將扮演一位穿著太空服的小小隊長，降落在一個巨大的花園世界中。在這裡，草叢如同森林，瓶蓋和硬幣都是巨大的寶物。你需要指揮一群可愛的皮克敏小生物，一起探索世界、對抗敵人、收集寶物！

## 操控方式

### 📱 手機/平板（觸控）

| 操作 | 方法 |
|------|------|

## 遊戲機制

### 🌅 日數系統
- 每天有 **3 分鐘**的活動時間
- 太陽會沿著畫面頂部移動，顯示剩餘時間
- 日落前 30 秒會出現橘色警告
- **天黑時，沒有跟在隊長身邊的皮克敏會被夜行生物吃掉！**

### 🎯 投擲 & 戰鬥
1. 點擊目標位置，隊長會抓起一隻皮克敏拋出
2. 皮克敏命中敵人後會**附著在身上持續造成傷害**
3. 敵人會定期**甩動**，把皮克敏甩下來
4. 小心！敵人的大嘴會**吞食**靠近的皮克敏

### 📦 搬運 & 繁殖
1. 擊敗敵人會掉落 **Pellet**（花蜜球）
2. 皮克敏會把 Pellet 和寶物**搬運**回 Onion（洋蔥基地）
3. Onion 吸收後會**長出新的皮克敏苗**
4. 隊長走過皮克敏苗會自動**拔出**，獲得新皮克敏！

### 🧅 Onion（洋蔥基地）
- 皮克敏的家，像洋蔥一樣的飛船
- 紅色 Onion 和藍色 Onion 各管各色的皮克敏
- 把物品搬回 Onion → 產出新皮克敏

### 💧 水域
- 藍色皮克敏可以安全通過水域
- **其他顏色的皮克敏會溺水！** 3 秒內用吹哨召回可以救活

## 敵人圖鑑

### Bulborb（大眼蟲）
大大的身體上有紅色斑點，巨大的眼睛和嘴巴。
- 平時在**睡覺** 💤，靠近或攻擊會驚醒
- 醒來後會**追擊隊長**
- 可以**吞食**皮克敏
- 擊敗後掉落大型 Pellet（可產出 5 隻皮克敏）

### Dwarf Bulborb（小眼蟲）
大眼蟲的迷你版，成群出現。
- 血量低，容易擊敗
- 擊敗後掉落小型 Pellet（可產出 2 隻皮克敏）

## 攻略小提示

1. **先拔苗！** 開始時隊長旁邊有皮克敏苗，走過去拔出來增加隊伍
2. **先打小的。** 先消滅小眼蟲練手，再挑戰大眼蟲
3. **從背後偷襲。** 趁大眼蟲睡覺時，從背後投擲皮克敏
4. **注意時間。** 日落前把皮克敏帶回 Onion 附近，別讓它們走失
5. **善用藍 Pikmin。** 過水域一定要用藍色皮克敏
6. **人多力量大。** 搬運寶物時，越多皮克敏搬運速度越快
